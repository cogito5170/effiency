## Goal
앞선 Claude/Agy 독립 검토를 반영해, 사용자가 그대로 실행할 수 있는 최종 16주 플랫폼·DevOps 취업 계획을 Claude가 작성한다. 모호한 선택지를 남기지 말고 주차별 일정, 공부, 구현, 자격증, 산출물, 완료조건을 확정한다.

## Constraints
- 사용자: 전자공학 학사, Python/C++ 경험, Linux·네트워크·클라우드 실무 경험 부족, 약 4개월.
- 목표: 국내 주니어 Platform/DevOps/Cloud/Developer Productivity/Workflow Automation 취업.
- 프로젝트: Reliable Job Platform. FastAPI, PostgreSQL, Python worker, Docker Compose, AWS, Terraform, GitHub Actions, logs/metrics/incident response.
- 범위를 줄이되 취업 포트폴리오로 충분한 깊이와 수치 기반 증거를 남긴다.
- Kubernetes와 EDA workload는 핵심 일정에 자동 포함하지 말고 명확한 gate가 있을 때만 stretch로 둔다.
- 교안은 사용자가 집필하는 일이 아니다. Claude/Codex가 구현 직전에 10–20분짜리 그림·문장·최소 코드·실습 교안을 제공한다. 사용자의 학습 시간을 잡아먹지 않도록 주당 수를 제한한다.
- 자격증은 실용성과 실무성, 프로젝트 완주 확률을 함께 고려해 필수/선택/제외를 단호하게 정한다.
- 12주차 feature freeze, 13–16주 검증·시험·지원 준비 원칙을 우선 검토한다.
- 하루 학습시간을 알 수 없으므로 주 20시간 기본안과 주 10시간 축소 규칙을 함께 제시한다.

## Done when
- 첫머리에 최종 범위와 자격증 결정을 명시한다.
- 16개 주차 각각에 시간 배분, 학습, 직접 구현, AI가 제공할 교안, 검증, 주간 산출물, 완료조건을 표로 작성한다.
- 프로젝트 MVP와 stretch를 분리한다.
- 매주 사용자가 AI 없이 직접 해야 할 핵심 작업을 1개만 지정한다.
- 4주·8주·12주·16주 gate와 지연 시 삭제 순서를 명시한다.
- AWS 비용 상한과 리소스 정리 규칙을 포함한다.
- 6주차부터 지원 준비를 시작하는 현실적인 지원 일정을 포함한다.
- 마지막에 바로 시작할 Day 1 체크리스트와 Claude에게 다음으로 보낼 프롬프트를 제공한다.

## Out of scope
- 코드 구현
- 원본 로드맵 파일 수정
- 사용자의 추가 선택을 요구하는 질문
- 취업 합격 보장
