# 과제: 구독형 AI 서비스 아이디어 브레인스토밍 (독립 조사)

목표: 사람들이 매달 돈을 낼 만한 AI 웹/앱 서비스 아이디어를 최대한 많이 (최소 15개) 낸다. 한국 시장 중심, 해외도 가능.
분야 제한 없음 (식품, 건강, 돌봄, 주거, 행정, 금융, 교육, 일, 여가 등). 사용자 스스로도 모르는 숨은 수요를 최소 5개 포함한다.

아이디어마다 근거는 두 가지다.
1. 불편함: 실제로 열어 본 웹 페이지의 수치나 사실 (공식 통계, 연구기관, 언론 보도). 숫자 + 출처 URL.
2. 아직 구현 안 됨: 비슷한 기존 서비스를 웹에서 검색해 본 결과. 찾은 서비스가 있으면 이름과 URL, 그것이 못 하는 부분. 못 찾았으면 "검색했으나 찾지 못함 (검색어: ...)".

수준: 박사급. 각 아이디어에 왜 이 불편함이 생기고 왜 아직 안 풀렸는지를 설명하는 학술 이론 1개 이상을 저자·연도·학술지로 인용한다 (예: 탐색비용, 행정 부담, 제한된 주의, 양면시장, 거래비용, Jobs-to-be-Done, 카노 모형 등). 실재하는 논문만 쓰고, 확실하지 않으면 쓰지 않는다.

규칙:
- URL 을 지어내지 않는다. 직접 연 페이지만 쓴다.
- 수치는 페이지에 적힌 그대로 쓴다. 추정이면 "추정"이라고 표시.
- 구독 적합도(높음/중간/낮음)와 이유 한 줄: 반복 사용 빈도, 무료 대체재 유무, 누가 돈을 내는지.

출력 형식 (Markdown 표 하나 + 끝에 "가장 유망한 3개와 이유" 3줄):
| # | 아이디어 (한 줄) | 불편함 근거 (수치, URL) | 미구현 근거 (검색 결과, URL) | 이론 근거 | 구독 적합 |
